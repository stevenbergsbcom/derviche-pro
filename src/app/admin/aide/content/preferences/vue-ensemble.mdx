Section **réservée aux <RoleBadge role="super-admin" />**. Rassemble toute la configuration fine de la plateforme, organisée en **12 onglets** accessibles depuis le sous-menu « Préférences » dans la sidebar.

## Les 12 onglets

| Onglet | Rôle |
|---|---|
| **Organisation** | Nom, email, téléphone, adresse, site web, saison |
| **Page d'accueil** | 6 blocs : hero, avantages, spectacles, impact, contact, footer |
| **Classement** | Spectacles en vedette + ordre global (drag&drop) — [voir](/admin/aide/spectacles/vedette-classement) |
| **Apparence** | Logos, favicon, thème (couleurs custom) |
| **Email** | Configuration expéditeur (Resend), test connexion |
| **Templates** | 12 modèles d'email éditables (sujet, corps, options) |
| **Notifications** | Quels événements déclenchent une cloche admin + emails alertes |
| **Rappels** | Configuration J-7 / J-2 / H-4 (heure d'envoi, activation) |
| **Calendar** | Statut Google Calendar + reconnection OAuth |
| **RGPD** | Politique de confidentialité éditable |
| **Légal** | Mentions légales, CGU, politique confidentialité |
| **Statistiques** | Colonnes visibles par défaut, période par défaut |

## Navigation

Depuis la sidebar admin, clic sur **« Préférences »** déploie le sous-menu. Clic sur un onglet → navigation directe + l'onglet reste surligné.

## Sauvegarde

**Chaque onglet** a son propre bouton « Enregistrer » en bas de page (sauf Classement qui sauvegarde automatiquement après chaque drag&drop).

Si vous modifiez un onglet et tentez de changer d'onglet **sans enregistrer**, une fenêtre de confirmation vous prévient : « Modifications non sauvegardées ».

## Accès restreint

Les <RoleBadge role="admin" /> ne voient pas le sous-menu Préférences dans la sidebar. Seul un <RoleBadge role="super-admin" /> peut modifier ces paramètres.
