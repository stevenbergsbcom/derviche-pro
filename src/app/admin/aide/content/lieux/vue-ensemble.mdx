Les **lieux** (ou **venues**) sont les salles de théâtre où se déroulent les spectacles. Chaque créneau est lié à un lieu.

## Accéder à la liste

**Lieux** dans la sidebar → liste complète avec recherche et tri alphabétique.

## Créer un lieu

Bouton **« Nouveau lieu »**. Champs :
- **Nom** (obligatoire)
- **Adresse** (rue, code postal, ville)
- **Capacité** (nombre de places)
- **Accessibilité PMR** (oui / non)
- **Parking** (oui / non + description libre)
- **Transports** (métro / bus / parking / autre — texte libre)
- **ID CRM (Zoho)** (optionnel)

Les infos d'accessibilité et transports apparaissent sur la fiche publique du spectacle (bloc « Informations pratiques »).

## ID CRM (Zoho)

Le champ **ID CRM (Zoho)** permet d'associer le lieu à sa fiche correspondante dans votre CRM Zoho. Il s'agit d'un identifiant numérique (~17 chiffres) que vous trouvez dans l'URL de la fiche lieu sur Zoho.

- **Optionnel** — vous pouvez laisser le champ vide
- **Unique** — un même ID ne peut pas être attribué à deux lieux différents
- **Numérique uniquement** — les caractères non chiffrés sont automatiquement retirés à la saisie
- **Apparaît dans les exports** — pour faire le pont avec votre CRM (à partir de la session S175)

## Modifier un lieu

Clic sur la ligne → édition. Les modifications se répercutent sur **tous les créneaux** existants liés à ce lieu (ex. si vous corrigez l'adresse, les emails futurs auront la bonne adresse).

## Supprimer un lieu

<Callout type="warning">
Un lieu **ne peut pas être supprimé** s'il est utilisé par au moins un créneau. Supprimez ou déplacez d'abord les créneaux concernés.
</Callout>

## Créer un lieu rapidement depuis un créneau

Pas besoin de passer par cette page si vous créez un créneau pour un lieu inédit : le dialog de création de créneau propose **« Créer un nouveau lieu »** directement.
