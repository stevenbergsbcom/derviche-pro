Vous pouvez exporter la liste des réservations **filtrées** en CSV ou Excel pour les partager, les imprimer ou les analyser dans un tableur.

## Comment exporter

1. Ouvrez **Réservations**.
2. **Appliquez vos filtres** (spectacle, lieu, période, statut, recherche…) : l'export reprend exactement la même vue.
3. Cliquez sur le bouton **« Exporter »** en haut à droite.
4. Choisissez le format :
   - **CSV** — universel, léger, ouvrable partout
   - **Excel (.xlsx)** — mise en forme préservée, prêt pour Excel / Google Sheets / LibreOffice
5. Le fichier se télécharge immédiatement dans votre navigateur.

## Colonnes exportées

L'export reprend **les colonnes visibles** du tableau. Pour ajouter / retirer des colonnes :

1. Cliquez sur l'icône des colonnes (en haut du tableau).
2. Cochez / décochez les colonnes.
3. Votre sélection est sauvegardée pour les prochaines fois.

Colonnes disponibles :
- Pro (nom, prénom, email, téléphone, structure, fonction, ville, code postal, pays)
- Spectacle, Compagnie
- Créneau (date, heure, lieu)
- Statut (Confirmée, Annulée, etc.)
- Check-in (présent, coup de cœur, presse, absent)
- Nombre de places
- Notes internes Derviche (⚠ ne jamais partager en dehors de l'équipe)
- Demandes spéciales
- Code de réservation
- Dates (création, modification)
- **ID CRM (pro)** et **ID CRM (lieu)** — identifiants Zoho (~17 chiffres), masqués par défaut
- **Adresse séparée** : Rue / Code postal / Ville en 3 colonnes (en plus de la colonne « Adresse complète »)
- **UUID pro** et **UUID lieu** — identifiants techniques Supabase, utiles uniquement pour le support technique (super-admin)

### Spécifique CRM Zoho

Les colonnes **ID CRM (pro)** et **ID CRM (lieu)** font le pont avec votre CRM Zoho. Activez-les depuis le sélecteur de colonnes pour les inclure dans vos exports.

Les valeurs sont automatiquement **forcées en format texte** dans le fichier généré pour éviter le piège classique d'Excel qui convertit `70611000000487416` en `7,06E+16` (notation scientifique) et corrompt la donnée. Cela fonctionne identiquement en Excel et CSV.

<Callout type="info">
**CSV vs Excel** : les deux formats préservent désormais les IDs CRM. Le CSV utilise une formule Excel (`="..."`) qui s'évalue en chaîne textuelle ; visible si vous ouvrez le fichier dans un éditeur de texte, transparent dans Excel.
</Callout>

<Callout type="warning">
**Côté compagnie (export depuis /company/reservations)** : l'ID CRM du pro n'est exposé que pour les réservations **sans compte** (guest). Pour les réservations faites par un pro connecté à son compte, le champ reste vide côté export compagnie — la jointure vers la fiche du pro n'est pas autorisée par les règles d'accès actuelles. Si la compagnie a besoin de cet ID, l'admin peut le fournir via l'export admin qui n'a pas cette limitation.
</Callout>

<Callout type="warning">
**Protection des données personnelles** : un fichier exporté contient des emails, téléphones et parfois adresses. Stockez-le en lieu sûr et supprimez-le dès qu'il n'est plus nécessaire (RGPD).
</Callout>

<Callout type="tip">
**Export rapide d'un spectacle** : filtrez par spectacle + « À venir » + exportez → vous obtenez la liste des invités à imprimer pour l'accueil sur place.
</Callout>
