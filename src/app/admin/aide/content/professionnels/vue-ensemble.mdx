Les **professionnels** sont les responsables de salles qui réservent vos spectacles. Cette base centralise toutes leurs informations.

## Accéder à la liste

**Professionnels** dans la sidebar → tableau paginé avec recherche, filtres, colonnes configurables.

## Recherche & filtres

- **Recherche** : nom, email, téléphone
- **Filtre Statut** : Actif / Inactif
- **Filtre Ville** (dropdown)

## Colonnes configurables

Cliquez l'icône **« Colonnes »** pour choisir ce que vous voyez : nom, email, téléphone, ville, code postal, pays, structure, fonction, date création, nombre de réservations, etc.

Votre sélection est **sauvegardée** (réutilisée à la prochaine visite).

## Fiche d'un pro

Clic sur une ligne → drawer latéral avec :
- **Coordonnées complètes**
- **ID CRM (Zoho)** — voir section dédiée ci-dessous
- **Historique des réservations** (toutes, avec détail spectacle / créneau / statut)
- **Toggle Actif / Inactif**

## ID CRM (Zoho)

Le champ **ID CRM (Zoho)** permet de relier la fiche pro à son enregistrement dans votre CRM Zoho. Il s'agit d'un identifiant numérique (~17 chiffres) trouvable dans l'URL de la fiche contact sur Zoho.

- **Optionnel** — laissez vide si le pro n'a pas (encore) de fiche dans votre CRM
- **Unique** — un même ID ne peut pas être attribué à deux pros différents
- **Numérique uniquement** — les caractères non chiffrés sont retirés automatiquement à la saisie
- **Source de vérité pour les réservations** — quand un pro connecté à son compte réserve, son ID CRM est hérité automatiquement (pas besoin de le ressaisir sur chaque résa)

Pour une réservation sans compte (guest), l'ID CRM se saisit directement sur la fiche de la réservation — voir [Modifier / annuler une réservation](/admin/aide/reservations/modifier-annuler).

## Désactiver un pro

Un pro **inactif** est masqué de la sélection lors d'une création de réservation (ne pollue pas la recherche). Ses réservations existantes restent intactes.

Cas d'usage : pro qui n'est plus en poste, demande RGPD de désactivation, etc.

## Exporter la base

Bouton **« Exporter CSV »** → fichier avec les colonnes visibles.

Depuis S175, le CSV inclut systématiquement (en fin de fichier) :
- **ID CRM Zoho** — au format texte (formule `="..."` lue par Excel), pour préserver les 17 chiffres
- **UUID (technique)** — identifiant Supabase, utile uniquement pour le support technique

<Callout type="warning">
**Attention RGPD** : un export contient des données personnelles. Stockez-le en lieu sûr et détruisez-le après usage.
</Callout>

## Supprimer un pro

La suppression est **irréversible** et **supprime aussi ses réservations**. À réserver à une demande formelle de droit à l'oubli.
