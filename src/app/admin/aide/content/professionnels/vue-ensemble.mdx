Les **professionnels** sont les responsables de salles qui réservent vos spectacles. Cette base centralise toutes leurs informations.

## Accéder à la liste

**Professionnels** dans la sidebar → tableau paginé avec recherche, filtres, colonnes configurables.

## Recherche & filtres

- **Recherche** : nom, email, téléphone
- **Filtre Statut** : Actif / Inactif
- **Filtre Ville** (dropdown)

## Colonnes configurables

Cliquez l'icône **« Colonnes »** pour choisir ce que vous voyez : nom, email, téléphone, ville, code postal, pays, structure, fonction, date création, nombre de réservations, etc.

Votre sélection est **sauvegardée** (réutilisée à la prochaine visite).

## Fiche d'un pro

Clic sur une ligne → drawer latéral avec :
- **Coordonnées complètes**
- **ID CRM (Zoho) — contact** + **ID CRM structure (Zoho)** — voir section dédiée ci-dessous
- **Historique des réservations** (toutes, avec détail spectacle / créneau / statut)
- **Toggle Actif / Inactif**

## ID CRM Zoho — deux identifiants distincts

Un professionnel porte **DEUX** identifiants Zoho indépendants :

### ID CRM (Zoho) — contact
Identifie **la personne** dans votre CRM (la fiche contact). Numérique, ~17 chiffres, trouvable dans l'URL de la fiche contact sur Zoho.

- **Optionnel**
- **Unique** — un même ID ne peut pas être attribué à deux pros différents
- **Source de vérité** pour les réservations avec compte : l'ID est hérité automatiquement

### ID CRM structure (Zoho)
Identifie **l'organisation pour laquelle travaille le pro** (la fiche structure dans votre CRM). Numérique, ~17 chiffres.

- **Optionnel**
- **PAS d'unicité** — plusieurs pros peuvent dépendre de la même structure (collègues d'une même MJC, théâtre, conservatoire…), donc le même ID se répètera légitimement
- **Source de vérité** pour les réservations avec compte : hérité automatiquement comme l'ID contact

### Comportement commun
- **Numérique uniquement** : caractères non chiffrés retirés automatiquement à la saisie
- **Pour les résa sans compte (guest)** : les deux IDs se saisissent directement sur la fiche de la réservation — voir [Modifier / annuler une réservation](/admin/aide/reservations/modifier-annuler)
- **Pas d'ID CRM côté lieu** : par décision produit, les salles (`venues`) ne portent aucun ID CRM. L'ID structure vit sur le pro.

## Désactiver un pro

Un pro **inactif** est masqué de la sélection lors d'une création de réservation (ne pollue pas la recherche). Ses réservations existantes restent intactes.

Cas d'usage : pro qui n'est plus en poste, demande RGPD de désactivation, etc.

## Exporter la base

Bouton **« Exporter CSV »** → fichier avec les colonnes visibles.

Le CSV inclut systématiquement (en fin de fichier) :
- **ID CRM Zoho (contact)** — au format texte (formule `="..."` lue par Excel), pour préserver les 17 chiffres
- **ID CRM Zoho (structure)** — idem
- **UUID (technique)** — identifiant Supabase, utile uniquement pour le support technique

<Callout type="warning">
**Attention RGPD** : un export contient des données personnelles. Stockez-le en lieu sûr et détruisez-le après usage.
</Callout>

## Supprimer un pro

La suppression est **irréversible** et **supprime aussi ses réservations**. À réserver à une demande formelle de droit à l'oubli.
