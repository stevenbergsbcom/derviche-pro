Un professionnel arrive sans avoir réservé ? Ajoutez-le en quelques secondes depuis l'app check-in.

## Depuis l'écran 3 (réservations d'un créneau)

1. Ouvrez le créneau concerné.
2. En bas à droite, un **bouton flottant gold « + »** apparaît.
3. Tapez-le → un formulaire rapide s'ouvre.

## Les étapes du walk-in

### 1. Recherche du pro

Commencez par **chercher le pro** dans la base :

- **Par email** (exact)
- **Par nom** (recherche partielle, insensible à la casse)

Si le pro existe → sélectionnez-le → infos pré-remplies.

Si le pro n'existe pas → cliquez **« Créer un nouveau professionnel »**.

### 2. Infos rapides

Pour un nouveau pro, champs minimaux :
- **Prénom, nom**
- **Email** (pour lui envoyer le post-accueil)
- **Compagnie / structure** (facultatif)
- **Téléphone** (facultatif)

### 3. Notifications

Par défaut, **aucun email** n'est envoyé pour un walk-in (le pro est déjà sur place).

Si vous voulez quand même lui envoyer une confirmation avec le code de réservation, cochez la case.

### 4. Check-in immédiat

Option pour **marquer la réservation directement comme « Présent »** dès sa création — gain de temps : une action au lieu de deux.

Cochez **« Enregistrer + check-in »** et validez.

## Ce qui se passe

- Une **réservation est créée** dans la base, statut « Confirmée »
- La réservation est **consommée sur la capacité du créneau**
- Elle apparaît immédiatement dans la liste, à la fin
- Si vous avez coché le check-in, le statut « Présent » est appliqué

<Callout type="warning">
**Si la capacité du créneau est atteinte** au moment du walk-in, le système refuse la création. Vous devez d'abord libérer une place (annulation d'une résa, transfert).
</Callout>

## Bonne pratique — gestion du surbooking

Si vous acceptez régulièrement des walk-ins au-delà de la capacité réelle, voyez plutôt avec un super-admin pour **augmenter la capacité déclarée** du créneau en amont. Mieux vaut connaître la capacité réelle.

## Rattrapage sur une représentation passée <RoleBadge role="super-admin" /> <RoleBadge role="admin" />

Le bouton flottant « + » peut aussi être utilisé pour rattraper une réservation oubliée sur une représentation d'un jour antérieur (par exemple : invité présent hier soir mais non enregistré).

- Depuis l'écran d'accueil, choisissez le spectacle → une case **« Inclure les représentations passées »** apparaît sous le sélecteur de spectacle.
- Cochez-la : les représentations passées apparaissent alors dans la liste, triées du plus récent au plus ancien.
- Chaque créneau passé porte un badge orange **« Passée »**.
- **Email de confirmation** et **synchronisation Google Calendar** sont **décochés automatiquement** dès que vous sélectionnez un créneau passé — vous pouvez les re-cocher manuellement si nécessaire.

<Callout type="info">
Cette option est réservée aux <RoleBadge role="super-admin" /> et <RoleBadge role="admin" />. Elle n'apparaît pas pour le rôle <RoleBadge role="externe" />, ni pour <RoleBadge role="company" />. Vous pouvez aussi passer par [le dialog admin « Nouvelle réservation »](/admin/aide/reservations/creer#rattrapage-sur-une-repr%C3%A9sentation-pass%C3%A9e) qui expose exactement la même option.
</Callout>
