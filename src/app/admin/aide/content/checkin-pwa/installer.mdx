L'application **Check-in** (`/accueil`) est une **PWA** (Progressive Web App) — pas d'App Store, elle s'installe directement depuis votre navigateur.

## Pourquoi installer l'app ?

- Icône sur l'écran d'accueil, ouverture plein écran (sans barre d'URL)
- Chargement plus rapide (cache)
- Interface optimisée tactile
- Pas besoin de se reconnecter à chaque fois

## Installation sur iPhone / iPad (Safari)

1. Ouvrez Safari et rendez-vous sur `https://derviche-pro.vercel.app/accueil` (ou l'URL de votre instance).
2. Connectez-vous avec vos identifiants.
3. Appuyez sur le **bouton Partage** ![Partage](data:,) (carré avec flèche vers le haut) en bas de l'écran.
4. Faites défiler et appuyez sur **« Sur l'écran d'accueil »**.
5. Confirmez avec **« Ajouter »**.

L'icône Derviche apparaît sur votre écran d'accueil. Tapez dessus → app en plein écran.

## Installation sur Android (Chrome)

1. Ouvrez Chrome et rendez-vous sur l'URL d'accueil.
2. Connectez-vous.
3. Une **bannière « Installer l'application »** apparaît en bas (ou dans le menu ⋮ → « Installer l'application »).
4. Appuyez sur **« Installer »**.

## Installation sur Mac / PC (Chrome, Edge, Safari)

L'app peut aussi s'installer sur un ordinateur :

1. Ouvrez l'URL dans Chrome / Edge.
2. Dans la barre d'adresse, cliquez sur l'icône **« Installer »** (✚) ou allez dans ⋮ → « Installer l'application ».

## Générer un QR code pour partager l'app

Dans le **tableau de bord admin**, bouton **« QR Check-in »** → affiche un QR code vers `/accueil`. Vos collaborateurs externes peuvent le scanner pour ouvrir directement l'app sur leur téléphone.

<Callout type="tip">
**Gain de temps sur place** : avant le jour J, installez l'app sur tous les téléphones qui vont l'utiliser. Connectez chacun avec son propre compte (<RoleBadge role="externe" /> pour les ponctuels, <RoleBadge role="admin" /> pour l'équipe).
</Callout>

## Mise à jour de l'app

La PWA se met à jour **automatiquement** au lancement quand une nouvelle version est déployée. Si quelque chose semble cassé, fermez l'app et rouvrez-la pour charger la dernière version.
