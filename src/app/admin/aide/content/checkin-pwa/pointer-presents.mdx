Le cœur du métier du jour J : pointer qui est arrivé, avec quelle qualité, pour alimenter les emails post-accueil et les statistiques.

## Les 4 statuts de check-in

Sur chaque ligne de réservation, 4 pastilles cliquables :

- **🟢 Présent** (cas standard) — le pro est venu
- **⭐ Coup de cœur** — le pro a particulièrement aimé (ouvre des emails de remerciement ciblés)
- **📰 Presse** — le pro est journaliste / critique
- **🔴 Absent** — le pro n'est pas venu

<Callout type="info">
Vous ne pouvez sélectionner **qu'un seul statut à la fois**. Cliquer sur un autre bascule instantanément.
</Callout>

## Comment pointer

1. Ouvrez le créneau (écran 3 — voir [Se repérer dans l'app](/admin/aide/checkin-pwa/naviguer)).
2. À l'arrivée d'un pro, trouvez-le dans la liste (recherche rapide par nom).
3. Cliquez sur la **pastille correspondant à son statut**.

La sauvegarde est **immédiate** (auto-save, pas de bouton à valider). Un petit icône de chargement apparaît pendant la requête. Les compteurs en-tête (Présentes / Total) se mettent à jour en temps réel.

## Ce qui déclenche l'email post-accueil

<Callout type="tip">
Cocher un statut **ne déclenche pas automatiquement** d'email. Voir [Envoyer les emails post-accueil](/admin/aide/checkin-pwa/emails-post-accueil) pour les envoyer manuellement (ou depuis le panneau latéral d'une réservation).
</Callout>

## Corriger une erreur

Cliquez sur la **même pastille** pour l'enlever, ou sur une autre pour basculer. La dernière action gagne.

## Ajouter une note de check-in

Chaque réservation peut avoir :
- **Note d'accueil** (visible par la compagnie)
- **Note interne Derviche** (jamais visible par la compagnie ni le pro)

Ces champs sont éditables depuis l'écran 3 via le panneau qui s'ouvre au clic sur une ligne.

## Cas particuliers

- **Un pro non prévu arrive** → voir [Ajouter une réservation de dernière minute](/admin/aide/checkin-pwa/walk-in).
- **Un pro prévu ne vient pas** → cliquez « Absent ». Un email de suivi peut être envoyé derrière, voir [Emails post-accueil](/admin/aide/checkin-pwa/emails-post-accueil).
- **Un pro doit partir plus tôt / transférer** → icône de transfert sur sa ligne, voir [Transférer une réservation](/admin/aide/reservations/transferer).

## Après le spectacle

Les statuts de check-in alimentent automatiquement :
- Les **statistiques** (taux de présence par spectacle / par lieu)
- L'**historique** du pro (visible dans son profil)
- Les **compteurs** affichés dans le tableau admin

Ils permettent aussi d'envoyer des emails de remerciement ou de suivi différenciés.
